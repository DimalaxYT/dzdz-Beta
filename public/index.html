Important pour le QR code dans cette preview

La preview Arena/e2b peut demander un header de sécurité nommé e2b-traffic-access-token. Un téléphone qui scanne le QR code n’a pas ce header, donc il peut afficher “Missing Traffic Access Token”. Ce n’est pas un bug de DropQR : pour scanner depuis un vrai téléphone, lance le site sur ton réseau local ou déploie-le sur un domaine public.
