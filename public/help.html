04 / Mode d’emploi

Le partage.
Sans détour.

Un navigateur suffit. Voici l’essentiel pour envoyer et recevoir un fichier avec DropQR.

Envoyer un fichier

  1. Sur l’accueil, ouvrez les options si vous souhaitez changer la durée ou permettre plusieurs téléchargements.
  2. Appuyez sur Choisir un fichier ou, sur téléphone, Prendre une photo. Un seul fichier est envoyé par transfert. Sur l’accueil, l’envoi commence automatiquement ; sur la page Envoyer, confirmez avec le bouton d’envoi.
  3. Gardez la page ouverte pendant le transfert. Vous pouvez l’annuler tant que la finalisation n’a pas commencé.
  4. Une fois prêt, copiez le lien, utilisez le partage natif du téléphone ou téléchargez le QR.

Recevoir un fichier

Ouvrez le lien reçu ou scannez le QR avec l’appareil photo de votre téléphone. Le nom et la taille du fichier s’affichent avant le téléchargement.

Si vous avez seulement le code, rendez-vous sur Recevoir. Vérifiez les informations, puis appuyez sur Télécharger le fichier.

Quelles sont les limites ?

Limite actuelle : selon la configuration du serveur. L’hébergeur peut appliquer ses propres limites de taille, de stockage ou de durée des requêtes.

Les fichiers sont envoyés par morceaux lorsque le serveur le permet. En cas de coupure, certains morceaux sont réessayés automatiquement. Si l’envoi échoue, gardez le fichier sélectionné et réessayez. Quitter la page interrompt le transfert.

Temporaire, par choix.

DropQR n’est pas un service de stockage permanent. Le fichier est supprimé à l’expiration, après le premier téléchargement si cette option est cochée, ou à votre demande.

Pour supprimer un fichier manuellement, utilisez les détails du résultat ou la page Mes transferts. Les clés de suppression restent enregistrées dans ce navigateur et sont envoyées au serveur uniquement lors d’une demande de suppression. Effacer la liste locale ne supprime pas les fichiers du serveur.

Et les vidéos ?

Un aperçu est proposé pour les fichiers vidéo compatibles avec votre navigateur. Il ne déclenche pas la suppression après téléchargement. Si la vidéo ne se lit pas, téléchargez-la pour l’ouvrir avec votre lecteur habituel.

Déployer DropQR

Le transfert nécessite le serveur Node.js. Un hébergement uniquement statique ne suffit pas. Utilisez Render, Railway ou un serveur compatible avec Node.js 18 ou plus récent.

npm ci
npm start

Configurez PUBLIC_URL avec votre adresse HTTPS publique pour obtenir des liens et QR accessibles depuis un autre appareil. Consultez le README du projet pour les options et la connexion Discord.
