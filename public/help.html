Pourquoi le QR peut être bloqué dans la preview ?

La preview Arena/e2b protège parfois l'URL avec un header de sécurité appelé e2b-traffic-access-token. Le navigateur Arena possède ce contexte, mais un téléphone qui scanne le QR ne l'a pas.

Conclusion : ce message ne signifie pas que le QR est cassé. Pour un test mobile réel, utilise l'URL publique Render ou un serveur lancé sur ton réseau local.

Tester sur le même Wi-Fi

Depuis ton ordinateur, lance le serveur avec l'adresse IP locale de la machine :

PUBLIC_URL="http://192.168.1.25:3000" npm start

Ouvre ensuite cette même adresse sur le téléphone. Le pare-feu doit autoriser le port 3000 et les deux appareils doivent être sur le même réseau.

Déployer sur Render gratuit

Le service peut fonctionner avec son stockage local pour des transferts temporaires. Un redémarrage ou un redéploiement peut toutefois supprimer les fichiers actifs. Ce mode convient à une utilisation personnelle ou à une petite bêta.

Configure au minimum :

PUBLIC_URL=https://ton-service.onrender.com
MAX_FILE_SIZE=500mb
DEFAULT_TTL_MINUTES=15
MAX_TTL_MINUTES=60
CHUNK_SIZE_MB=4
UPLOAD_CONCURRENCY=2

Le service peut aussi s'endormir sur le plan gratuit. Le premier accès après une période inactive peut donc demander un peu de patience.

Routes utiles

  • GET /api/health — état et version du serveur.
  • GET /api/config — configuration publique de l'interface.
  • POST /api/transfers — upload classique.
  • POST /api/transfers/chunk — upload par morceaux.
  • POST /api/transfers/complete — assemblage final.
  • GET /api/codes/:code — recherche par code.
  • DELETE /api/transfers/:id — suppression avec clé privée.
  • GET /download/:id — récupération du fichier.

Le nettoyage des transferts expirés est exécuté automatiquement toutes les minutes.

Envoyer une vidéo

Les vidéos sont transférées comme les autres fichiers. La page de réception propose un lecteur intégré grâce à /view/:id. Les requêtes Range permettent au lecteur d'avancer sans télécharger toute la vidéo.

Publier le code sur Discord

Un webhook suffit pour envoyer le code et le QR dans un salon. Il n'est pas nécessaire de créer un bot complet.

  1. Ouvre les paramètres du salon Discord.
  2. Va dans Intégrations, puis Webhooks.
  3. Crée un webhook et copie son URL.
  4. Ajoute les variables sur Render.
DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/...
DISCORD_USERNAME=DropQR
DISCORD_NOTIFY=true

Ne place jamais un token de bot dans le code ou dans le dépôt.

Ce que le stockage local implique

Les métadonnées sont conservées dans storage/db.json et les fichiers dans storage/files. C'est rapide et sans coût, mais ce n'est pas une sauvegarde permanente.

Pour une version plus robuste, un stockage objet comme R2, B2 ou S3 pourra être ajouté plus tard. Pour l'instant, garde des durées courtes et une limite adaptée aux ressources gratuites.
