DropQR a besoin d’un backend Node.js

Si tu vois cette page sur Netlify après avoir glissé-déposé le ZIP complet, c’est normal : Netlify Drag & Drop héberge du statique et ne lance pas server.js.

Pour que l’upload, le QR code et les téléchargements fonctionnent, déploie le dossier sur Render, Railway, Fly.io, un VPS, ou lance-le localement avec npm start.

Commandes locales :

npm install
npm start

Pour un téléphone sur le même Wi-Fi :

PUBLIC_URL="http://IP_DE_TON_PC:3000" npm start
